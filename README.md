# Planning chantiers Atlas Énergie

Application installable (téléphone, tablette, PC) du planning chantiers d'Atlas Énergie.

- Adresse de l'appli : https://atlas-energie.github.io/planning-atlas-energie/
- Ce dépôt ne contient que les écrans de l'appli. Les données du planning (chantiers, heures, photos) sont rangées dans le Google Drive de l'entreprise et ne sont accessibles qu'après connexion (code reçu par mail).
- Les notifications passent par Firebase Cloud Messaging (projet « Planning Atlas »).
